# 日序 · Dayline

这是适配 GitHub Pages 的静态网页版本。项目不需要构建：仓库根目录里的 HTML、CSS、JavaScript 和图标文件直接托管。

## 发布

1. 新建一个公开 GitHub 仓库，把本目录中的所有文件放在仓库根目录。
2. 打开仓库的 Settings → Pages。
3. 在 Build and deployment 中选 Deploy from a branch，分支选 main，目录选 /(root)。
4. 等待 GitHub Pages 发布后，用显示的网址打开。

## 记录与隐私

计划、日记和复盘存在当前浏览器的本机存储，不会上传到 GitHub，也不会跨设备自动同步。可以在软件的“设置与备份”中导出和导入 JSON 备份。

GitHub 免费账户的 Pages 仓库需要公开，因此本仓库中的软件源代码会对所有人可见。
